# GitHub Workflow Practice

这个小仓库用于练习 GitHub 分支、Pull Request（PR）和合并流程，并记录成就条件的验证。

## 一次完整的 PR 流程

1. 从默认分支创建一个描述清晰的功能分支。
2. 做一项具体修改，检查内容后提交。
3. 推送分支，创建 PR，说明解决的问题和验证结果。
4. 检查 PR 的差异，再合并到默认分支。
5. 更新本地默认分支，让本地和远程保持一致。
